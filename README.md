# URL TO HTML Telegram Bot

## Local
Set the environment variable `BOT_TOKEN` to your BotFather token, then run:

    pip install -r requirements.txt
    python bot.py

## Render
Create a **Background Worker** and connect this repository.
Build command:

    pip install -r requirements.txt

Start command:

    python bot.py

Add an environment variable:

    BOT_TOKEN = your BotFather token

The bot only has one main feature: URL TO HTML.
